# calendar_features.csv — 출처와 컬럼 정의

생성 코드: `build_calendar.py` (실행: `python build_calendar.py`)
기간: 2025-01-01 ~ 2026-10-31, 하루 1행 (669행). 조인 키는 `date` (YYYY-MM-DD).
모든 항목은 예측 기준일 **2026-06-30 이전에 공개·확정된 일정**만 사용했습니다.

## 0. 규칙 변경 (2026-11-11 운영진 안내)
- **7월 이후 정보는 지하철 승하차 실측(정답)을 제외하고 모두 사용 가능**합니다. 날씨 실측, 실제 경기 결과 등이 포함됩니다. *(공지 링크 기록 필요)*
- 이에 따라 `features.EXTERNAL_MODE = "actual"`(기본값)로 두고 아래를 반영했습니다.
  - 문학 야구: 2026-07~10 실제 경기 결과(우천취소·재편성·포스트시즌·실제 개시 시각)를 사용합니다.
  - 날씨: 인천 시간별 날씨 실측을 2025-01부터 2026-10까지 사용합니다.
  - NEIS: 학기 중 변경 여부를 따질 필요가 없어졌습니다. 적재 시점과 상관없이 사용합니다.
- 이전 방식(기준일에 공개된 정보만 사용)은 `EXTERNAL_MODE = "as_of"`로 그대로 재현할 수 있습니다.
- 승하차 관련 피처(`sdh_*`, `st_*`, `lag364` 등)는 지금도 각 기준일까지의 실측만 사용합니다. 누출 테스트도 통과했습니다.
- 2026년 7~10월에 추가 임시공휴일은 지정되지 않았습니다. 9/28 임시공휴일은 검토됐지만 지정되지 않아 평일로 처리했습니다. 근거: https://www.wikitree.co.kr/articles/1161815

> - 인증키는 `neis_key.txt`(제출물 제외)에서 읽으며, 원본 JSON에는 키가 포함되지 않습니다.
> - 방학일 판정: 이름에 '방학'이 들어간 일정(방학식·개학·종업·졸업 제외) + '방학식' 다음날~'개학' 전날(80일 이내). 기록 사이 4일 이하 빈칸은 방학으로 채움. 일정이 아예 없는 5개교는 제외, 방학 기록이 불완전한 6개교는 '방학 아님'으로 집계됨(전체의 1% 수준).

## 2. 데이터 대조 결과 (train.csv)

같은 달·같은 요일 평상시 평일 대비 일 총승차 비율:
- 평일 공휴일 0.53 ~ 0.63, 노동절(2026) 0.68
- 설·추석 당일 및 전후 0.32 ~ 0.47
- 징검다리 평일 0.76 ~ 0.85 (2025-10-10, 2025-12-26, 2025-01-31)
- 2025-05-01 근로자의날(당시 비공휴일) 0.66 → `is_quasi_holiday`
- 위 항목 외에 원인을 알 수 없는 평일 급감일(<0.85)은 **없음**

방학 효과 (평상시 평일, 역×시간×연도 평균 대비 log 차이):
- 대학 방학: 전체 -0.05, **인천대입구 -0.20**(학기 중 대비 약 -27%), 경인교대입구 -0.08
- 초·중·고 방학: 전체 -0.07, 7시 통학 시간대 인천대입구 -0.14, 부평 -0.06
- 방학 학교 비율 구간별 7시 승차 (log 차이): 0~10% +0.04 / 10~50% −0.05 / 50~90% −0.10 / 90% 이상 −0.11 → 비율이 높을수록 단조 감소
- 여름휴가 극성수기: 전체 -0.10

## 3. 컬럼 정의

| 컬럼 | 의미 |
|---|---|
| date | YYYY-MM-DD |
| year, month, day, dow | dow: 0=월 … 6=일 |
| day_of_year, week_of_year | ISO 주차 |
| is_weekend, is_saturday, is_sunday | 주말 |
| holiday_name, holiday_type | 공휴일 이름 / national·lunar·substitute·temporary |

| is_election | 선거일 |
| is_quasi_holiday, quasi_name | 공휴일은 아니나 출근자가 줄어드는 날 (2025 근로자의날, 12/31) |
| is_offday | 주말 또는 공휴일 |
| is_weekday_holiday | 평일에 걸린 공휴일 |

| is_long_weekend | 3일 이상 연휴 |
| days_to_next_offday, days_from_prev_offday | 가장 가까운 휴무일까지 일수 |

| is_bridge_day | 양옆이 휴무인 평일 (징검다리) |
| is_pre_long_offday, is_post_long_offday | 3일 이상 연휴 직전·직후 평일 |
| is_first_workday, is_last_workday | 휴무 직후 첫 평일 / 휴무 직전 마지막 평일 |
| is_school_vacation | 초·중·고 절반 이상이 방학 (NEIS 기준: 2025-07-22~08-17, 2026-01-08~02-28, **2026-07-23~08-17**) |
