# 출처와 이용 조건 보존

이 폴더 전체에 새 일괄 라이선스를 부여하지 않습니다. 팀 코드의 별도 공개 라이선스는 이 작업에서 확인하지 않았습니다. 공식 대회 원본 CSV는 포함하지 않습니다. OOF 캐시는 공식 train에서 파생된 라벨을 포함하므로 공개 독립 데이터로 취급하지 않습니다.

외부 위키 문서의 기여자·원문 URL·필드 추출 및 CSV 정규화 내역은 [저작자표시 목록](evidence/CC_ATTRIBUTION.csv)에 있습니다. 해당 문서가 명시한 [CC BY-NC-SA 2.0 KR](https://creativecommons.org/licenses/by-nc-sa/2.0/kr/) 조건과 비상업·출처표시·동일조건을 보존합니다. 사진·포스터를 새 예측 입력으로 복제하지 않았습니다. 정확한 revision ID는 원 감사에서도 미확보였습니다.

수치의 대체 출처 확인이 과거 수집 경로의 이용 허락을 소급해 확정하지는 않습니다. KBO·주거·일부 행사와 축제의 보류 상태는 SOURCES.md와 README에 남겼습니다. 이 폴더를 Kaggle Dataset 구조로 묶었다는 사실도 공개 재배포 허락을 뜻하지 않습니다.

TabICL 체크포인트는 이 2단계 폴더에 없습니다. 1단계에서 사용한 모델의 BSD-3-Clause 고지는 1단계 패키지에서 보존해야 합니다. numpy와 pandas 자체도 이 ZIP에는 동봉하지 않습니다.
