## 2. Public 리더보드 활용 및 최종 후보 선정

- 각 후보에 적용한 값과 계수는 **과거 자료를 이용한 검증으로 먼저 결정·기록**한 뒤, 완성된 후보를 Public 리더보드에 한 번씩 제출했습니다.
- **Public 점수를 확인한 뒤 기존 후보의 값을 수정하지는 않았습니다.** 다만 앞선 제출 결과를 알고 있는 상태에서 다음에 실험할 구성을 선택한 경우는 있습니다.
- 예를 들어 주성분 5개 구성(0.143777)을 제출한 후, 과거 검증을 통해 주성분 12개·30개 구성(각각 0.143545, 0.143123)을 정해 제출했고, 이후 시간대 층을 추가한 구성(0.143043)을 제출했습니다.
- 최종 예측에는 **주성분 30개 구성에 시간대 층을 추가한 후보**를 채택했습니다. 주성분 12개·30개 및 시간대 층 적용 여부에 따른 후보 가운데 Public 성능을 기준으로 선택했습니다.

후보별 제출 내역과 Public 점수 전체 목록은 `METHOD.md` **7절**에 있습니다.

## 3. 예측 기간 중 타 노선 지하철 승차 실측 사용 — 운영진 확인 필요

### 3.1 사용 자료와 적용 범위

| 항목 | 상세 내용 |
|---|---|
| 데이터 출처 | 서울 열린데이터광장 OA-12914, 「서울시 지하철호선별 역별 승하차 인원 정보」(일별) |
| 이용 조건·저작권 표시 | 공공누리 제1유형 / 서울특별시·코레일·공항철도 |
| 다운로드 일시 | 2026년 11월 13일 오후 |
| 데이터 기간 | 2025년 1월 1일~2026년 10월 31일(총 669일) |
| 필터링 후 범위 | 7호선 전체와 지정 환승역을 제외한 **26개 노선, 561개 역** |
| 실제 계산에 사용한 범위 | 전체 669일 데이터가 있는 **544개 역** |
| 사용 위치 | **4단계(`code/4_rail/`)에만 적용**. 1~3단계에는 미사용 |
| 활용 방식 | ‘변화 옮기기’, ‘공휴일류 수준’, ‘시간대별 반응’의 세 층에 입력 |
| 계수 결정 | **2026년 6월 30일 이전** 자료의 과거 9개 기준일 검증으로 결정. 2026년 7~10월 타 노선 실측은 해당 날짜의 입력값으로 사용 |

**제외한 역·노선의 세부 기준**

- 인천 1·2호선: OA-12914 자료 자체에 없음.
- 서울 7호선: 전체 제외.
- 7호선 역과 이름이 같은 역: 온수, 가산디지털단지, 대림, 총신대입구(이수), 고속터미널, 강남구청, 건대입구, 군자, 상봉, 태릉입구, 노원, 도봉산, 보라매.
- 인천 1·2호선 환승역: 부평, 주안, 원인재, 계양, 검암, 부천종합운동장, 인천시청, 부평구청, 석남.

전체 제외 목록: `code/4_rail/cache/ban_list.json`

### 3.2 대회 규칙과 구두 안내 내용

대회 규칙 **제4절**에는 다음 행위가 금지된 것으로 기재되어 있습니다.

> “어떤 경로로든 2026년 7월 이후의 실제 지하철 승차·하차 인원을 찾아보거나 사용하는 행위”

이 **문구 자체만 보면 타 노선의 2026년 7월 이후 승하차 인원도 금지 범위에 포함**될 수 있습니다. 반면 팀장이 운영진으로부터 구두로 전달받았다고 공유한 내용은 다음과 같습니다.

| 시점 | 팀장이 전달한 안내 내용 | 확인 형태 |
|---|---|---|
| 2026년 11월 13일 오후 | 인천 1·2호선 및 서울 7호선의 7월 이후 승하차 기록은 사용하지 말고, 그 외는 허용된다는 취지 | 팀장에 따르면 구두 설명 |
| 같은 날 약 19:40 | “나머지 지하철 데이터셋은 써도 된다”는 취지 | 팀장에 따르면 구두 설명 |

**현재 이 구두 설명에 대한 서면 답변은 확보하지 못했습니다.** 따라서 타 노선 지하철 실측의 사용이 대회 규정에 부합한다고 확정하지 않고, 운영진의 확인을 요청드립니다.

**비교 가능한 산출물:** 타 노선 지하철 실측을 사용하는 4단계를 적용하기 전의 3단계 결과는 `submission_xgb7_w10_on_curvature.csv`(Public **0.144715**)입니다. 재현 과정에서 중간 산출물로 생성되며, 최종 선택된 예측 파일은 아닙니다.

## 4. 예측 대상 역의 2026년 7월 이후 실측 처리 내역

**대상:** 인천 1·2호선 및 서울 7호선 인천·부천 구간.

- **학습·검증·보정에 사용한 대상 역의 실제 승하차 인원은 대회 제공 `train.csv`의 2026년 6월 30일 이전 자료뿐입니다.** 대상 역의 2026년 7월 이후 실측은 예측 계산에 사용하지 않았습니다.
- 다만 OA-12914 월별 원본 자료에는 서울 7호선 행이 포함되며, 여기에 대회 예측 대상 역이 들어 있습니다. 수집 스크립트 `code/4_rail/fetch/fetch_all.py`는 원본 파일을 읽은 직후 7호선 및 환승역 행을 제거하고 원본 파일을 삭제하도록 구성했습니다. **해당 값은 출력하거나 집계하지 않았습니다.**
- 2026년 11월 13일, 팀원 한 명이 별도의 인접 노선 자료 묶음을 전달했습니다. 팀원의 설명상 그 원자료 폴더에는 전 노선이 포함됩니다. **모델 작업에서는 이 묶음을 열거나 계산에 사용하지 않았습니다.** 다만 해당 팀원이 원자료를 어느 범위까지 열람했는지는 본 문서 작성자가 확인하지 못했습니다.

## 6. 수집·검토했으나 최종 예측에 반영하지 않은 자료와 점검

- **OA-12252:** 「서울시 지하철 호선별 역별 시간대별 승하차 인원 정보」(월별·시간대별 합계)를 2026년 11월 13일 내려받아 경인선·수인선의 25개 역만 남겼습니다. 과거 검증 결과 채택하지 않아 **어떤 제출 파일에도 사용하지 않았습니다.**
- **파업·지연 영향 점검:** 2026년 11월 13일 약 19시, 사용 가능하다고 구두 전달받은 타 노선 자료를 바탕으로 2026년 9월 14~18일과 10월 28~30일의 평균 증감을 확인했습니다. **이 점검으로 예측값을 변경하지 않았습니다.**
